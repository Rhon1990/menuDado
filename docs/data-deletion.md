# Solicitud de Eliminacion de Datos de MenuDado

Ultima actualizacion: 6 de julio de 2026

MenuDado permite usar la app como invitado, crear una cuenta con correo y contrasena o iniciar sesion con Google. La app puede guardar datos localmente en el dispositivo y, cuando hay conexion, sincronizar datos mediante Firebase bajo el usuario invitado anonimo o la cuenta registrada.

## Como eliminar datos locales

Puedes eliminar los datos locales de MenuDado de estas formas:

- Borrar menus desde la propia app.
- Borrar los datos de la app desde los ajustes de Android.
- Desinstalar MenuDado del dispositivo.

Esto elimina los datos guardados localmente en el dispositivo, como menus, preferencias del perfil alimentario, onboarding y contador local de uso de IA.

## Como solicitar eliminacion de datos sincronizados o de cuenta

Para solicitar la eliminacion de datos asociados a MenuDado, escribe a:

rhonal.delgado@gmail.com

Incluye en el mensaje:

- Asunto: `Eliminar datos de MenuDado`.
- Nombre de la app: `MenuDado`.
- Si tienes cuenta registrada, escribe preferiblemente desde el correo asociado a esa cuenta.
- Pais desde el que usas la app, si quieres indicarlo.
- Modelo aproximado del dispositivo, si quieres indicarlo.
- Cualquier detalle que ayude a identificar la instalacion o el problema.

No envies contrasenas, documentos oficiales, datos financieros ni informacion medica sensible.

Si usas MenuDado solo como invitado, puede ser mas dificil localizar datos sincronizados porque estan asociados a un identificador anonimo de Firebase. En ese caso, indica cualquier detalle que ayude a identificar la instalacion, pero no incluyas informacion sensible.

## Que datos se eliminaran

Cuando sea posible identificar los datos asociados a la solicitud, se eliminaran o desvincularan los datos sincronizados de MenuDado, como:

- Menus guardados, incluyendo notas, ingredientes, favoritos, fotos asociadas cuando correspondan, calorias estimadas y analisis IA.
- Perfil alimentario, incluyendo preferencias, alergias y alimentos o condiciones indicadas por el usuario.
- Estado de onboarding.
- Uso diario de IA y datos tecnicos necesarios para gestionar pausas temporales.
- Metadatos de la app asociados al usuario, como version de app, version de Android, fabricante/modelo, pais configurado, zona horaria y estado de cuenta.
- Cuenta de Firebase Authentication asociada, cuando la solicitud permita identificarla y corresponda eliminarla.

Los datos agregados o anonimizados de analitica pueden conservarse cuando no permitan identificar directamente a una persona o una instalacion concreta, de acuerdo con las politicas de Firebase/Google y la configuracion del servicio.

## Datos que pueden conservarse

Pueden conservarse datos agregados, anonimizados o registros tecnicos necesarios para seguridad, prevencion de fraude, diagnostico de errores, cumplimiento legal o funcionamiento de servicios de Google/Firebase, siempre que no permitan identificar directamente a una persona desde MenuDado.

## Plazo de respuesta

Las solicitudes se revisaran y responderan por correo electronico en un plazo razonable. Si hace falta informacion adicional para localizar los datos, se pedira por el mismo correo.
